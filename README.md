# ArtistsHub

ArtistsHub - современная веб-платформа для поиска и открытия новых музыкальных исполнителей. Проект помогает пользователям быстро находить артистов, фильтровать их по параметрам, просматривать карточки и получать подробную информацию в одном месте.

## Демо

Live Demo: https://onixframe-dev.github.io/artist-hub/

## О проекте

Проект решает задачу удобного доступа к базе музыкальных исполнителей. Пользователь может просматривать список артистов, использовать поиск и фильтры, открывать подробную информацию об исполнителе и читать отзывы.

Основные возможности:

- Загрузка артистов из внешнего API.
- Поиск и фильтрация исполнителей.
- Пагинация списка артистов.
- Модальное окно с подробной информацией об артисте.
- Секция отзывов.
- Форма отправки отзыва.
- Адаптивная верстка для mobile, tablet и desktop.

## Технологии

Проект собран на фронтенд-стеке:

- HTML5
- CSS3
- JavaScript ES6+
- Vite
- Axios
- Swiper
- Choices.js
- iziToast
- tui-pagination
- modern-normalize
- PostCSS

Это vanilla JavaScript проект: без React, Vue, Angular или Next.js.

## Структура проекта

```text
src/
  assets/       шрифты и SVG-иконки
  css/          базовые стили и стили секций
  js/           API, компоненты, рендер и утилиты
  partials/     HTML-части страницы
  public/       публичные изображения и favicon
```

## Локальный запуск

1. Клонировать репозиторий:

```bash
git clone https://github.com/onixframe-dev/artist-hub.git
```

2. Перейти в папку проекта:

```bash
cd artist-hub
```

3. Установить зависимости:

```bash
npm install
```

4. Запустить dev-сервер:

```bash
npm run dev
```

После запуска Vite покажет локальный адрес, обычно:

```text
http://localhost:5173/
```

## Сборка

Создать production-сборку:

```bash
npm run build
```

Проверить production-сборку локально:

```bash
npm run preview
```

## Деплой

Проект деплоится на GitHub Pages через GitHub Actions.

Исходный код находится в ветке `main`, собранный сайт публикуется из ветки `gh-pages`.

URL опубликованного сайта:

```text
https://onixframe-dev.github.io/artist-hub/
```
